# 自己位置推定を実機で回す — 手順

**対象**: この PC (macOS) から SSH で Rock5A の機体に繋いで実験する人
**道具**: [`scripts/loc.sh`](../scripts/loc.sh) と `cmd/loc_replay`
**最終更新**: 2026-09-23

---

## 0. これは何をするか

推定器を**機体の上で実際に回す**。走行機能には一切触らない。
推定は観測に徹し、結果は 3 か所に出る。

| 見る場所 | 何が見えるか |
|---|---|
| ロボットのログ (`[EST]` の行、1 秒ごと) | 位置・速度・共分散・倍率・NIS・滑り率・更新回数を 1 行で |
| `http://<robot>:9191/localization` | 同じ内容の JSON + 警告 |
| MCAP (`/est/state`, `/est/innovation`, `/est/timing`) | 後から `loc_replay` で全部追える |

**制御へは繋がない。** 指令プロトコルが決まってからにする (計画 P6)。

---

## 1. 最初の 1 回だけ

```bash
# ロボットに公開鍵を入れる (すでに入っていれば不要)
ssh-copy-id -i ~/.ssh/id_ed25519.pub root@<robot>
```

鍵が無ければ `ssh-keygen -t ed25519` で作る。`loc.sh` は
**BatchMode でパスワードを待たない**ので、鍵が入っていないと即座に失敗する
(固まるより良い)。

---

## 2. 毎回の流れ

```bash
# 1) ロボットを見つける (DHCP で IP が変わる)
scripts/loc.sh find            # ARP キャッシュから MAC で引く
scripts/loc.sh find --sweep    # 見つからなければサブネットを一巡 (会場では周りに配慮)
export ROBOT=172.15.0.xx       # 分かっているなら直接

# 2) 状態を見る
scripts/loc.sh check           # SSH・サービス・ディスク・動いているプロセス・HTTP

# 3) 送り込む
scripts/loc.sh deploy          # クロスビルドして SSH の標準入力で流し込む

# 4) 走らせる (Ctrl+C で止まり、サービスが元に戻る)
scripts/loc.sh run

# 5) 取り出す
scripts/loc.sh fetch           # MCAP を logs/ へ
scripts/loc.sh restore         # 念のため (run が落ちたときなど)
```

解析:

```bash
go run ./cmd/loc_replay -log logs/racoon-loc-*.mcap             # 概要
go run ./cmd/loc_replay -log logs/racoon-loc-*.mcap -compare    # 機能ごとの効果
go run ./cmd/loc_replay -log logs/racoon-loc-*.mcap -qsweep     # Q を NIS で合わせる
```

### 設定 (環境変数)

| 変数 | 既定 | 意味 |
|---|---|---|
| `ROBOT` | find の結果 | ロボットの IP |
| `ROBOT_MAC` | `20:bd:1d:d7:3f:f2` | find が探す MAC |
| `TEAM` | `blue` | **自機の色。取り違えると相手のロボットを自機だと思い込む** |
| `VISION_IFACE` | `wlan0` | ロボット側で vision を受ける NIC |
| `VISION_DELAY_MS` | `0` | vision の定数遅延の補償。`loc_replay` が測った値を入れる |
| `GEOMETRY` | (組み込みの有効値) | 機体パラメータ JSON。機体を替えたら測り直す |

## 3. 走っている間に見るもの

1 秒ごとにこういう行が出る。

```
[EST] OK pos 1277,-0 mm th -0.0 deg | v 400,0 mm/s w -0.00 rad/s | sigma 0.3 mm |
      vision 0 ms ago | k_v 0.993 k_w 1.000 | NIS 0.81 slip 0.05 noise x1.02 |
      wheel 399 vision 400 zupt 0 reset 0 | act 88ms | 24 us
```

| 見るところ | 正常 | ずれていたら |
|---|---|---|
| `wheel` / `vision` の回数 | どちらも増え続ける | **片方が止まったら時刻の対応が壊れている** (実機で車輪が 0 回になった事故がある) |
| `sigma` | 数 mm | 数十 mm なら vision が来ていないか共分散が開いている |
| `NIS` | **3.0 に近い** | 3 より大きい = Q か R が小さすぎ、小さい = 大きすぎ。**真値が要らないので実機で Q を決めるのはこれ** |
| `slip` | 0.05 以下 | **0.5 を超え続けるなら滑っているのではなく幾何が違う** |
| `noise` | 1.0 前後 | 車輪雑音モデルが実機と合っていない |
| `k_v` / `k_w` | 1.00 ± 0.05 | 大きく離れたら公称の寸法が違う。収束値を `-locgeometry` へ反映する |
| `reset` | 0 | 増えるならフィルタが発散している |
| 最後の µs | 50 未満 | 1 周期 8 ms に対する処理時間 |

**異常があると `[EST] WARNING:` の行が出る。** 出たらその場で止めて原因を見る。

## 4. 安全

- **`-locestimate` はロボットを動かさない。** 推定は観測だけ。
- **`-locident` は自走する。** 機体パラメータの加振で、周囲を空けて人がそばにいるときだけ。
  `loc.sh run -locident` は 5 秒の猶予を置いてから始める。
- **STM に指令途絶のタイムアウトが無い。** Pi のプロセスが死ぬと**最後の速度で走り続ける**。
  `loc.sh run` は ssh の標準入力を握ったまま起動するので、手元を切ると EOF でロボット側も終わる。
  **この仕掛けを外さないこと。**
- **自己更新を必ず止める。** `loc.sh` は `-noupdate` を渡し、さらにビルド時に
  バージョンを `(devel)` に固定して二重に止めている。止めないと、新しいリリースが出た瞬間に
  **走行中のバイナリが上書きされて落ちる** (PoC で実際に起きた)。
- **終わったらサービスを戻す。** `loc.sh run` は Ctrl+C でも異常終了でも戻す (trap)。
  不安なら `scripts/loc.sh restore`。

## 5. はまりどころ (PoC で実際に踏んだもの)

| 症状 | 原因 | 対処 |
|---|---|---|
| `scp` が固まる / 失敗する | **この機体に sftp-server が無い** | `loc.sh` は `ssh 'cat >'` で流し込む。`scp` を使わない |
| 自分のシェルが死ぬ | `pgrep -f` / `pkill -f` が**自分のコマンド行にも一致する** | `ps -eo pid,comm,args` で comm を見て選ぶ |
| IP が変わっている | DHCP | `loc.sh find`。ホスト鍵は同じなので警告は出ない |
| vision が 1 つも来ない | NIC を取り違えている (有線と無線) | `VISION_IFACE=wlan0` |
| 別のロボットを自機だと思っている | チーム色 / ID の取り違え | `TEAM` を確認。`cmd/vision_list` 相当で模様の位置を先に確かめる |
| 電池が減ると追従がずれる | **指令が効くまでの遅れが電池電圧で変わる** | `[EST]` の `act` (実測の遅れ) を見る。固定値にしない |
| ディスクが埋まる | MCAP は 10 分で数十 MB | `loc.sh clean`、`fetch` してから消す |

## 6. 実験の前に決めておくこと

**今のデータには、推定器の値打ちが出る条件が 1 つも入っていない。**
撮るなら下を優先する (研究文書 §6.5 に理由がある)。

| 優先 | 条件 | 何が決まるか |
|---|---|---|
| ★★★ | vision の欠落 0.5〜2 s | 推定器の本命。旧版との差もここでしか出ない |
| ★★★ | 停止を含む走り | ZUPT の効果、止まり際のクリープ |
| ★★☆ | 速い走り 1〜3 m/s | **車輪雑音モデルは 0.35 m/s までしか測っていない。試合の速度域は外挿** |
| ★★☆ | ヨーレートを振る走り | ジャイロが載ったとき `b_g` と `k_w` を分離するのに必須 |
| ★☆☆ | 意図的な滑り | スリップ状態と冗長残差の検証 |
| ★☆☆ | フィールドの中央・端での静止 | vision の絶対精度 |

**どれも 4 輪の回転速度が記録されている状態で。**
